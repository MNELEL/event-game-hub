## מטרה

לאפשר לערוך את 4 שאלות הדמו (טקסט / תמונה / וידאו / נכון-לא-נכון) שמופיעות במקטע `#demo` בדף הנחיתה — דרך טאב חדש בממשק הניהול, בלי לגעת בקוד.

## איפה הנתונים נשמרים

**localStorage** (key: `landing_demo_questions`) — פשוט, ללא צורך בשינויי DB/RLS, נטען מיידית, ועובד גם לאורחים אנונימיים שצופים בדף הנחיתה (קורא את אותו key מאותו דומיין).

קונפיגורציית ברירת המחדל הקיימת תישאר fallback אם אין כלום ב-localStorage.

## מה ייווצר/ישתנה

### 1. `src/data/landingDemo.ts` (חדש)

- מגדיר `DemoQuestion` type ו-`DEFAULT_DEMO_QUESTIONS` (ה-4 הקיימות).
- `loadDemoQuestions()` / `saveDemoQuestions()` — קריאה/כתיבה ל-localStorage עם try/catch ו-fallback.
- אירוע custom `demo-questions-updated` ש-Landing מאזין לו לרענון מיידי כשעורכים בטאב אחר.

### 2. `src/components/landing/InteractiveQuestionDemo.tsx` (עדכון)

- במקום מערך `QUESTIONS` קבוע — `useState` שנטען מ-`loadDemoQuestions()`.
- מאזין לאירוע `demo-questions-updated` ול-`storage` event לעדכון חי.

### 3. `src/components/admin/DemoQuestionsEditor.tsx` (חדש)

טופס לעריכת 4 השאלות:

- בחירת איזו מ-4 לערוך (טקסט/תמונה/וידאו/נכון-לא-נכון) דרך Tabs.
- שדות לכל שאלה: כותרת השאלה, רשימת תשובות (Input × N), בחירת תשובה נכונה (RadioGroup).
- לסוגי תמונה/וידאו: שדה URL + כפתור "העלה" שמעלה ל-Supabase Storage לבאקט ציבורי `demo-media` ומחזיר public URL.
- תצוגה מקדימה של התמונה/וידאו.
- כפתורי "שמור", "אפס לברירת מחדל", ו"תצוגה מקדימה בדף הנחיתה" (פותח `/#demo` בטאב חדש).

### 4. `src/pages/Admin.tsx` (עדכון)

הוספת טאב חדש "דמו נחיתה" (אייקון `Sparkles`) שמרנדר את `DemoQuestionsEditor`. רשת הטאבים תעלה ל-7 עמודות.

### 5. Storage bucket חדש (migration)

- `demo-media` — public, RLS מאפשרת INSERT למשתמשים מאומתים בלבד; SELECT לכולם.

## פרטים טכניים

- אין שינוי schema בטבלאות.
- `qid` של כל שאלה (`text` / `image` / `video` / `boolean`) הוא קבוע — מבטיח שתמיד יש בדיוק 4 סוגים.
- ולידציה: לפחות 2 תשובות, אינדקס נכון ≤ אורך התשובות, URL חוקי לתמונה/וידאו.
- הגנה: כל הקוד שעורך נמצא תחת `/admin` המוגן ב-`ProtectedRoute`.
