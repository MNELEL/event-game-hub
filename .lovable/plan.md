## 1. README.md מורחב

**מיקום:** `README.md` (החלפה מלאה של הקיים)

**תוכן:**
- כותרת + תיאור קצר (עברית + EN).
- צילומי מסך / GIF placeholders.
- **תכונות עיקריות**: ניהול שאלות, משחק רב-משתתפים, טיימר מסונכרן, אנליטיקה, אופליין/PWA, תארי סיום.
- **טכנולוגיות**: React 18, Vite, Tailwind, Framer Motion, Recharts, Lovable Cloud (Supabase), Capacitor.
- **מבנה תיקיות** (עץ).
- **Routes** (טבלה).
- **Backend & אבטחה**: RLS, Edge Functions, anti-spoofing, user_roles נפרד.
- **התקנה לפיתוח** (`bun install`, `bun dev`).
- **בנייה ל-Android** (Capacitor + GitHub Actions APK).
- **שימוש**: יצירת משחק → לובי → QR → הצטרפות → תוצאות.
- **קרדיטים**.

## 2. דף "אודות" באפליקציה

**מיקום:** `src/pages/About.tsx` + רישום ב-`src/App.tsx` תחת `/about`.

**עיצוב:**
- רקע `game-gradient` (parchment).
- כרטיס מרכזי `parchment-card` עם `parchment-border-double` ו-`watercolor-corners`.
- כותרת בזהב (`text-game-gold text-shadow-game`), אנימציית bounce-in.
- אייקונים מ-lucide בתוך עיגולים זהובים.
- כפתור חזרה לבית.

**מבנה תוכן (RTL):**
1. כותרת: "🧠 אודות מגה מוח".
2. פסקת תיאור קצרה.
3. **גריד 2x3 של פיצ'רים** (כל אחד עם אייקון, כותרת, משפט):
   - שאלות בעברית · רב-משתתפים · טיימר מסונכרן · אנליטיקה חיה · אופליין & PWA · תארי סיום חגיגיים.
4. **בלוק "איך משחקים"** — 3 צעדים ממוספרים.
5. **בלוק טכנולוגיה** קצר (Lovable Cloud, Realtime, אבטחה).
6. **קרדיט יצירה** + טלפון `03-7737970` (סטטי, ללא קישור — בהתאם לזיכרון הפרויקט).
7. כפתורי CTA: "הפעלת משחק" / "הצטרפות".

**קישור גישה:**
